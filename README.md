# Grocery Optimizer

Grocery Optimizer is a consumer application that answers one question: where
should I buy the items on my grocery list to spend the least money? A shopper
builds a grocery list, compares it across grocery stores, and sees the
cheapest single-store trip alongside the cheapest plan using up to two stores,
including how much the extra stop saves and which items to buy where.

## Status

Mission 001 specification ready; implementation not started.

No application functionality exists yet.

## Technology Direction

- Frontend: React and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
